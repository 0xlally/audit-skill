# CVE 技能 / CVE Skill

这是一个面向 Codex 的技能，用于在明确授权的开源项目中开展高影响漏洞研究，重点寻找可信的 High/Critical 漏洞候选，并准备负责任披露所需证据。

This Codex skill supports authorized high-impact vulnerability research in open-source projects, with a focus on credible High/Critical candidates and responsible disclosure evidence.

Users of this skill are welcome to submit their own outputs through issues or pull requests. Please submit only authorized, already public, or non-sensitive information.

You can also install from repository `0xlally/CVE-skill` and path `critical-cve-search`.
