# CVE 技能

这是一个面向 agent 的技能，我主要使用 GPT-5.4，用于在明确授权的开源项目中开展高影响漏洞研究，重点寻找可信的 High/Critical 漏洞候选，并准备负责任披露所需证据，推荐搭配 Codex goal 模式一起使用。

英文主版本见 [README.md](README.md)。

## 常规模式

在使用 Codex 的过程中，有两点观察：

- 第一：误报率很高，包括夸大漏洞评级、不查看官方 security 说明等问题，这导致我们需要用大量时间去审核。可以用提示词来一定程度缓解，但是每次都输入提示词是一件很麻烦的事情，所以这个 skill 应运而生。
- 第二：Codex 挖洞会很多偏向于认证、越权、配置和参数几个方面，其他漏洞涉及得不太好，因此做了一个 skill 来引导挖洞，以高危漏洞为导向。

## 图模式

图模式主要是通过另一种挖洞思路来扩展常规模式的不足。如果常规模式跑了足够长时间依旧找不到漏洞，聪明的你发现，Codex 审计代码很像人的思维：去看项目有哪些安全问题，并追踪修复尝试绕过，以此为基础查看相关代码并审计。但你很快意识到它看到的代码是不完整的。聪明的你又想让 Codex 逐函数审计，可以做到无遗漏，但是许多函数是不可利用的，漏洞需要一条从入口到利用的完整链条，这就意味着上面的办法很低效。所以图模式解决以下问题：

- 第一：使用 CodeQL 建立函数关系图，扩展 Codex 挖洞的视野，审计更多路径。
- 第二：记录审计过的节点，避免无效的重复。
